# WoW Forever on Nagi

For a NixOS system with Lutris, use Lutris to install Battle.net in a writable Wine prefix under the user's home directory. Install WoW Forever from Battle.net and let Battle.net update it. Lutris documents its Battle.net installer and Wine setup in its [Battle.net guide](https://github.com/lutris/docs/blob/master/Battle.Net.md); Blizzard lists [Forever's November 4 launch and subscription requirement](https://worldofwarcraft.blizzard.com/en-us/news/24301508).

Use **WowUp with CurseForge** as the native Linux addon manager. [WowUp's client guide](https://wowup.io/guide/options/wow-clients) explicitly lists WoW Forever and its beta. The [CurseForge edition's 2.24.1 release](https://github.com/WowUp/WowUp.CF/releases/tag/v2.24.1) explicitly added Forever support. [WowUp's source guide](https://wowup.io/guide/get-addons/overview) confirms that the CurseForge edition searches CurseForge, WowUp Hub, and TukUI, while the Wago edition lacks CurseForge access. Its [Linux guide](https://wowup.io/guide/wowup/overview) describes the AppImage; the [latest CurseForge edition release](https://github.com/WowUp/WowUp.CF/releases/tag/v2.25.4) has a Linux AppImage. Nixpkgs also offers [`wowup-cf`](https://github.com/NixOS/nixpkgs/blob/nixos-unstable/pkgs/by-name/wo/wowup-cf/package.nix), currently packaged at 2.24.1 in the checked branch. That package controls the manager binary, not game or addon updates.

WowUp may not detect a game inside a Lutris Wine prefix. Use **Options > Clients > Add New** and choose the executable inside the Forever installation, as [WowUp's client guide](https://wowup.io/guide/options/wow-clients) directs. The live client is reported to use `_forever_` and `Wow.exe` by [the ForeverPlusPlus project's client inspection](https://github.com/xIGBClutchIx/ForeverPlusPlus/blob/main/docs/forever-api.md); the beta used `_classic_beta_` and `WowB.exe`. Thus, for a prefix at `~/Games/battlenet`, check `~/Games/battlenet/drive_c/Program Files (x86)/World of Warcraft/_forever_/`. Confirm the path from the actual Battle.net install before selecting it. Select the **Forever** client in WowUp before adding addons. The manager writes to that client's `Interface/AddOns` directory, and addons remain user-managed. [WowUp's client guide](https://wowup.io/guide/options/wow-clients) offers optional per-client auto-update; leave it off if updates should happen only when requested.

The official sources confirm product support and Linux downloads, but they do not prove that WowUp sees Nagi's specific Lutris installation or that every addon has a Forever build. Confirm the installed path and addon availability after the game is installed.
